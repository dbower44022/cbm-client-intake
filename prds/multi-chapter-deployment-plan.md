# Multiple chapters — moved

**This plan is now a project directory: [`prds/chapter-network/`](chapter-network/README.md).**

Split on 2026-08-24. The single 1,235-line document had started doing four jobs
at once — settled rulings, seven phase plans, dated measurements and an
unaddressed decision list — and it was also, unintentionally, the only place two
live production defects were written down. Nothing was summarized away in the
split: every section of the original is in one of the files below, and the
substance of the rulings is unchanged. The original text is in git history at
`6187f4c:prds/multi-chapter-deployment-plan.md`.

This file stays because the changelog, the session prompts in `prompts/` and the
commit history cite it by path.
